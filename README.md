# Sytem Monitor Script
A simple Bash script to monitor system resources (RAM and Disk usage).

## Features
* Checks current RAM usage percentage.
* Checks current Disk space usage percentage.
* Saves an alert message in a local log file ('alert.log') if the usage exceeds the limit.

## How to use
1. Open your terminal.
2. navigate to the folder where the script is located.
3. Run the script using the following command:
    '''bash
    base monitor.sh
